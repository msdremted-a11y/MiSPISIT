# Системный монитор на базе eBPF + Qt

Инструмент для мониторинга нагрузки Linux-систем: снимки загрузки CPU и
ввода-вывода для системного администратора.

Версия 0.0.5 — после сохранения снимка система создаёт уведомление:
на экране «Уведомления» видно сообщение о событии, какая запись его вызвала
и статус (новое / прочитано). Приложение, база и панель поднимаются вместе
одной командой. Окно Qt остаётся клиентским интерфейсом (папка `qt-client/`)
и в эту версию не входит.

## Запуск

    Репозиторий: https://github.com/msdremted-a11y/MiSPISIT
    Ветка: lab5
    Pull Request: https://github.com/msdremted-a11y/MiSPISIT/pull/5
    Образ: troykins/qt-ebpf-monitor:0.0.5
    Страница образа: https://hub.docker.com/r/troykins/qt-ebpf-monitor

    git clone -b lab5 https://github.com/msdremted-a11y/MiSPISIT
    cd MiSPISIT
    docker compose up -d

Страницы системы: http://localhost:8080
Панель Grafana: http://localhost:3000 (открывается сразу, без входа)

## Адреса

| Адрес | Что открывается |
|---|---|
| http://localhost:8080/ | Главная: название, версия, переходы к функциям, уведомлениям и панели |
| http://localhost:8080/snapshots/new | Форма: сохранить снимок нагрузки (из `/proc` или вручную) |
| http://localhost:8080/snapshots | Список сохранённых снимков |
| http://localhost:8080/snapshots/1 | Карточка одного снимка |
| http://localhost:8080/rejected | Отказ: кто пытался сохранить снимок и почему он не принят |
| http://localhost:8080/notifications | Уведомления: сообщения о сохранённых снимках, статус новое/прочитано |
| http://localhost:3000 | Панель Grafana «Системный монитор eBPF + Qt — 0.0.5» |

## Событие версии 0.0.5

Выбранный вариант — внутреннее уведомление человеку. Действие «сохранение
снимка нагрузки» создаёт запись в новой таблице `notification`
(время, какой снимок, текст сообщения, статус `new`/`read`). До действия
экран уведомлений пуст, после него появляется сообщение со ссылкой на снимок.
Второй вариант (экран наблюдения) не собирался: операционное состояние уже
показывает панель Grafana из версии 0.0.4.

## Сервисы

| Сервис | Образ | Порт | Назначение |
|---|---|---|---|
| `app` | `troykins/qt-ebpf-monitor:0.0.5` | 8080 | Страницы трёх функций и уведомлений (Go, html/template) |
| `db` | `postgres:16` | наружу не открыт | Хранение снимков, отказов и уведомлений, том `dbdata` |
| `dashboard` | `grafana/grafana:11.4.0` | 3000 | Панель по данным базы, ходит в `db` по имени сервиса |

Источник данных и экран Grafana лежат в `grafana/provisioning` и подключаются при старте.

## Структура

    cmd/web/main.go                         запуск сервера и адреса страниц
    internal/actions/                       три функции + создание уведомления при сохранении
    internal/storage/                       работа с PostgreSQL, создание таблиц (в т.ч. notification)
    internal/procstat/                      снятие нагрузки из /proc/stat и /proc/diskstats
    templates/, static/                     шаблоны страниц и оформление
    grafana/provisioning/datasources/       источник данных app (PostgreSQL, сервис db)
    grafana/provisioning/dashboards/        экран monitor.json и его подключение
    qt-client/                              окно Qt (клиентский интерфейс)
    Dockerfile                              образ приложения, linux/amd64 и linux/arm64
    docker-compose.yml                      приложение, база и панель вместе
